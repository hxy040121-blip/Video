## 0. 三条运行时事实（违反就会坏，已在 Chromium 里验证）

1. **clip-path 不能挂在 `.p-iris` 自己身上。** 网站用 CSS `transform` 平移 `.p-iris`；clip 挂在同一元素上时，裁切区域会跟着一起移动，虹膜就跑出眼白。必须外包一层：
   ```svg
   <g clip-path="url(#ID-eyeL)"><g class="p-iris"> …虹膜… </g> …静态的眼睑阴影… </g>
   ```
   （brief 里写的 `<g class="p-iris" clip-path=…>` 是错的，以本条为准。）
2. **`.p-eye` 和 `.p-iris` 上不要写 `transform` 属性。** 网站会用 CSS transform 覆盖它们（视线平移、眨眼 scaleY）。头部要歪，就把 `transform="rotate(…)"` 写在 `.p-head`（和 `.p-hair-back`）上。
3. **网站以 `overflow: visible` 显示 SVG。** 画出 0–600 × 0–800 之外的任何东西都会溢出到别的卡片上。所以：
   - `p-hair-back`、`p-body`、（画在头外的）`p-hand` 各包一层 `<g clip-path="url(#ID-frame)">`，`<clipPath id="ID-frame"><rect width="600" height="800"/></clipPath>`。
   - 跑出画面底边的形状一律画到 **y = 820**（不是 800），这样它的 5px 外轮廓落在裁切区外，底边不会出现一条黑线。
   - `p-head` 不裁切，所以头发、发饰、帽子必须自己留在 x 0–600、y ≥ 60 以内。

其他：所有 id 以 `<id>-` 开头；引用用 `href="#…"`（不用 xlink）；不要 `<text> <image> <script> filter`、不要外部引用；文件 ≤ 60 KB（样板 13 KB / 23 KB）。

## 1. 文件骨架（顺序固定）

```svg

    <clipPath id="ID-frame"><rect width="600" height="800"/></clipPath>

    <clipPath id="ID-eyeR"><path d="与右眼 p-sclera 相同"/></clipPath>
    <path id="ID-face" d="…"/>  <clipPath id="ID-face-c"><use href="#ID-face"/></clipPath>
    … 其他形状同理（ID-torso、ID-shirt、ID-hf 前发、ID-hb 后发 …）
  </defs>
  <g clip-path="url(#ID-frame)"><g class="p-hair-back"> 后发 / 马尾 / 披发 </g></g>
  <g clip-path="url(#ID-frame)"><g class="p-body"> 脖子+肩(肤色) → 衣服 → 领子/领带/饰物 </g></g>
  <g class="p-head">
    （近侧耳朵，画在脸之前）→ 脸 → 脸阴影 → 脸轮廓
    <g class="p-eye">左眼(画面左＝远侧)</g>  <g class="p-eye">右眼(画面右＝近侧)</g>
    眉 → 鼻 → 嘴 → 腮红/伤疤/妆
    （手碰到脸时：<g class="p-hand">…</g> 放这里）
    <g class="p-hair-front"> 头顶+刘海+鬓发 → 发丝线 → 发饰/帽子 </g>

```
左/右一律指**画面**左/右。脸朝画面左偏约 15°：画面左眼是远侧眼（窄），画面右眼是近侧眼（宽），近侧耳朵在画面右。

## 2. 赛璐璐“三明治”：每块色区都这样画

```svg
<use href="#ID-face" fill="#F9E3D6"/>                       <!-- 1 底色 -->
<g clip-path="url(#ID-face-c)">                              <!-- 2 阴影，被同一形状裁切，所以随便画出界 -->
  <path d="…" fill="#4a1a2a" opacity=".25"/>
</g>
<use href="#ID-face" fill="none" stroke="#0b0809" stroke-width="5" stroke-linejoin="round"/>  <!-- 3 外轮廓压在最上 -->
```
阴影形状永远是**硬边**平涂块，不用渐变；不用 `filter`。一块色区最多一层主阴影（头发另外可有一条高光带）。

## 3. 线

| 用途 | 粗细 | 备注 |
|---|---|---|
| 外轮廓：脸、头发团、脖子肩膀、衣服、手、马尾 | **5** | `stroke-linejoin="round"` |
| 小型闭合件：耳朵、拇指、发饰、领子尖、领带结、蝴蝶结 | **4–4.5** | |
| 内部线：发丝、衣褶、鼻、嘴、下眼睑、锁骨、手指缝 | **2.2–2.6** | `stroke-linecap="round"` |
| 微细节：双眼皮、指甲、睫毛尖、腮红斜线、指节 | **1.6–2** | 常配 `opacity=".45–.7"` |

线色一律 `#0b0809`。唯二例外：浅发色的眉毛用发色深调（盾子 `#b9775e`）；黑色衣物上的褶线用 `#4a4446`/`#5a5357`。上睫毛线**不是描边，是填充形状**（见 §6）。

## 4. 颜色与阴影

## 6. 眼睛（重点）

### 6.1 构造（由下到上）
```svg
<g class="p-eye">
  <path class="p-sclera" d="S" fill="#fbf7f4"/>
  <g clip-path="url(#ID-eyeR)">            <!-- 外包裁切（见 §0-1） -->
    <g class="p-iris">
      <ellipse cx="CX" cy="CY" rx="RX" ry="RY" fill="EYE"/>                                         ① 底色
      <path d="M(CX-RX) (CY-.18RY) A RX RY 0 0 1 (CX+RX) (CY-.18RY) C (CX+.5RX) (CY-.5RY) (CX-.5RX) (CY-.5RY) (CX-RX) (CY-.18RY) Z" fill="EYE_DK" opacity=".6"/>  ② 上部阴影帽（贴着虹膜轮廓的弧）
```

- `EYE` = `art.eyeColor`；`EYE_DK` = EYE 压暗约 45%（盾子 `#7BB8E8`→`#2b5d93`）；`EYE_LT` = EYE 提亮约 60%（→`#cfe9fb`）。
- 虹膜尺寸：男 近 rx15 ry19 / 远 rx13.5 ry18；女 近 rx17 ry21 / 远 rx15 ry19。虹膜**上下都要被眼睑吃掉一点**（ry 大于眼白半高），这样平移 ±7 / ±4.9 时眼睛不会“空”。
- 虹膜中心：近侧 (355, 330)，远侧 (251, 332)——两只都略偏画面右（脸朝左、眼睛看观众）。
- 上睫毛线是**月牙形填充**：内眼角端 2–3px，眼睑顶 7–9px（男）/10–14px（女），在外眼角处收成尖并伸出眼白 6–10px（女性加 1–2 根翘起的睫毛尖）。最粗的一端永远在**外眼角**。
- 远侧眼 = 近侧眼**水平镜像**再按 0.85 压窄（3/4 透视），这样眼线最粗端仍在外眼角（画面左）。底模里两只眼就是这样做出来的；不要直接平移复制近侧眼。
- 下眼睑只画外侧 2/3，2.2px；女性在外眼角加 1 根 1.8–2px 的下睫毛。

完整的男/女眼睛（含远侧镜像后的路径）直接从 `_templates/male.svg`、`_templates/female.svg` 复制，只改颜色。

### 6.2 表情变体（危险感从眼睛来）
- **死鱼眼 / 厌倦 / 冷**（盾子画面左眼）：眼白上沿压平到虹膜中线附近（`M218 336 C226 326 242 322 258 322 …`），睫毛线变平而厚，主高光换成 `#fff` .35 的小点或去掉，⑧ 透明度提到 .30。
- **瞪大 / 失眠**（L）：眼白更圆更高（L 近侧眼白 66×53），虹膜**比眼白小**一圈露出四白（这是唯一允许的例外），加黑眼圈：眼下月牙 `#4b3a5a` × .42。
- **眯眼 / 笑里藏刀**：眼白高 ≤ 22，上下睑都用填充线，虹膜仍完整画出并被裁。
- **闭眼 / 遮眼 / 绷带**：p-sclera 仍然存在（可以是一条 6–8px 高的缝或绷带缝隙），里面放一个小 `p-iris`（一个 r≈3 的反光点或一截虹膜），这样视线追随仍有反应。
- **单眼特殊瞳**（写轮眼、六芒等）：花纹画在 `p-iris` 内、瞳孔④之上、高光⑥之下。
- 高光只在“活”的眼睛里是亮白；疯狂/非人的角色可以去掉⑥只留⑦，或者把⑥换成签名色。

## 7. 眉、鼻、嘴

- 眉：**填充形状**，不是描边。男 5–7px 厚，女 3–4px。默认色 `#3a2a26`；浅发人用发色深调。远侧眉比近侧短 20%。眉形就是表情：压低内端＝凶，挑高＝轻佻，平直＝冷。
- 鼻：只画鼻尖一笔（从鼻梁下 1/3 弯到鼻尖再勾回鼻底）+ 右侧小三角阴影。不画鼻孔，不画鼻梁线。
- 嘴：一条 2.6px 线，宽 36–60；下唇一笔 2px .6 透明度在嘴线下 11px。张嘴时口腔填 `#6b1a2c`，舌头 `#e8798f` 或签名色。笑容只抬**画面右**半边嘴角最有不安感（盾子）。唇彩：下唇粉色月牙 .6 + 一个白色小高光。

## 8. 头发

1. **剪影优先。** 先只用黑色填出整团头发，缩到 80px 宽看能不能认出是谁。
2. **结构：** `p-hair-back`（脑后、披发、马尾，整体再叠一层阴影：深发 `#000` .45，浅发 `#4a1a2a` .30）→ `p-hair-front`（头顶+刘海+鬓发，一个闭合形状）→ 发饰。
3. **发束轮廓用“缺口–尖”交替的二次曲线**：缺口→尖 这一段向内凹（控制点向形状内偏 6–12px），尖→缺口 这一段向外凸（−6~−10px），得到弯钩状的发束；尖的长度要有长有短，不要锯齿般平均。生成工具（可选，在 /tmp 跑出路径再贴进来）：
   ```js
   // pts：[[x,y],…] 交替 缺口/尖；bends：每段的弯曲量（+ = 向行进方向右侧，顺时针轮廓里就是向内）
   function locks(pts, bends) { let d = `M${pts[0]}`; for (let i = 1; i < pts.length; i++) {
     const [ax, ay] = pts[i-1], [bx, by] = pts[i], L = Math.hypot(bx-ax, by-ay), b = bends[i-1] ?? 0
     d += ` Q${((ax+bx)/2 - (by-ay)/L*b).toFixed(1)} ${((ay+by)/2 + (bx-ax)/L*b).toFixed(1)} ${bx} ${by}` } return d + ' Z' }
   ```
4. **发丝线**：2.4–2.5px，从每个缺口出发朝发旋方向画 40–90px 的弧线，**不画满**，并用 `<g clip-path="url(#ID-hf-c)">` 裁在头发里（否则会画到脸上）。发旋大约在 (322,150)。
5. **阴影**：一块，覆盖头发画面右侧与后侧，边缘沿发束走成锯齿；再加鬓发内侧（贴脸那面）一条。
6. **高光带（天使环）**：一块，放在头顶**左上**，上沿是顺着头型的弧，下沿是一排向下垂的尖齿（顺发丝方向）。L：`M162 238 Q196 184 252 160 Q300 144 348 150 L342 162 L330 186 L322 166 L300 164 L290 196 L280 168 L258 176 L246 208 L240 182 L218 196 L204 230 L200 206 L182 226 L172 254 Z`。长发/马尾在弯折处再加一小块。
7. 刘海下缘就是额头投影的模板（§4）。
8. 黑发必须读得出来：底色不暗于 `#1d1a1c`，高光带要明显，必要时外缘加签名色细边（.35）。

## 9. 身体与手

- 衣服顺着底模的肩线画；领口、领带、扣子都对齐 x≈304 的中线（身体基本正面，只有头偏 15°）。
- 衣褶：2.5px 线 + 一两块阴影，褶子从领口/肩头向下放射。不要画满。
- 手（只在 art 里写明姿势时画）：手掌宽 ≈ 0.45 × 脸宽（≈ 95–110px），中指长 ≈ 0.55 × 脸宽。**手背和伸出的手指画成一个合并的剪影**（一条 5px 外轮廓绕过 V 字），弯曲的手指用 2.2px 线分开，指节用 1.8px .55。碰脸的手放在 `p-head` 里（L 的拇指），不碰脸的放到最后的 `p-hand`（盾子的剪刀手）。指甲是 2px 描边的小杏仁形 + 一点白高光。

## 10. 签名色 accent

- 至少一处，元素加 `class="p-accent"`，**用 `art.accent` 原值**。
- 放在**视线会停的小面积**上：领带、发饰、虹膜纹、舌尖、腮红、耳环、衬里、伤疤边。面积 ≤ 画面 5%（荧光粉类尤其克制）。
- 样板：L＝白衫的冷灰阴影（`#CFD8DC`，整组阴影 `<g class="p-accent">`）；盾子＝舌尖 + 腮红（`#FF3E9A`）。

## 11. 表情：每个人的“危险感”

不是“笑”或“不笑”，是**一处不对劲**：L 不眨的四白眼 + 拇指压唇；盾子半张脸在笑、半张脸死了（远侧眼死鱼眼 + 平嘴角，近侧眼闪亮 + 挑眉 + 吐舌 + 腮红）。先读 `art.expression`，找到那一处，然后让眼睛、眉、嘴角三者里至少两样去表现它。
