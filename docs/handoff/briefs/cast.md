# 板块：卡池（cast）与 十五席（table）

你的文件：`assets/js/sections/cast.js`、`assets/css/cast.css`、`assets/js/sections/table.js`、`assets/css/table.css`。

## 配置依据

- `CHARACTERS`：38 张人物卡的提炼数据（名字、称号 epithet、原作 work、性别、年龄、身高、年代、母语、判定七项 stats、随身物 carried、别人眼里 othersSee、原作台词 quote、梦想 dream、庭审台词 lines、立绘说明 art.accent 等）。
- `人物卡/00_卡司总则.md` §3：判定七项的含义与档位。
- `开局配置.md` §1：主持人在【装载】时列出本局登场的人物卡，一到十五张；列出的先后就是编号；醒来时编号几号就坐几号席。
- `洋馆物理层.md`：二层有一条「东肖像廊」（东侧走廊，挂着肖像）——卡池就设定在这条肖像廊里。

## cast（卡池）—— 东肖像廊

- **构图**：滚动时 pin 住，横向推进的一条幽暗长廊：38 幅肖像挂在墙上，每幅是一个细黄铜画框（可以有不同的哥特式框型，但要统一成一套），画框下有一块小铜名牌（名字 + 极小的称号）。墙面是暗色织锦纹（细微的 SVG 图案）。两三排错落或一排均可，以构图好看为准；38 幅要能在合理的滚动长度内看完。
- **光标是蜡烛**：靠近光标的画框被照亮（亮度、黄铜反光的位置随光标移动），远处的肖像几乎沉在黑里。所有肖像的眼睛都追随光标（`App.portrait` 自带）——当一整条长廊的眼睛同时转向你，这一刻要让人发毛。
- **悬停**：肖像从灰度（`is-mono`）渐变为彩色，画框轻微晃动一下（像被风吹动），名牌上的称号用 `App.text.scramble` 解码出来；音效 `hover`。
- **点击 → 档案**（用 `App.overlay.open`）：弹丸论破「通信簿」式的档案页，构图要大胆：
  - 一侧是巨大的肖像，背后斜切的角色签名色色块（`art.accent`），另一侧是竖排巨大的名字。
  - 称号、原作作品名、年龄 / 身高 / 年代（等宽小字，一行）。
  - **判定七项**画成一个七边形雷达图（体能与格斗、伪装、善于读人、医护、现场观察、杀人门槛、疑心），用描线动画画出来，档位映射成数值；悬停某一轴显示该项的原文档位和括号说明（`physiqueNote` 等，若有）。注意「杀人门槛」档位越低越危险——可以把这一轴染成血粉。
  - 随身物：小小的标签。
  - 「别人眼里」一句；原作台词用 `App.text.type` 打出来（中文大，原文小）；梦想一句。
  - 左右切换上一位/下一位（按钮 + 键盘 ←/→），切换时用斜切或硬切转场，音效 `slash`/`card`。
- `palette`：暗酒红/墨，光色暖金；`track: 'gallery'`。

## table（十五席）—— 装载

- **构图**：俯视的圆桌（与 prologue 的圆桌是同一张桌子，但这里是一个更「操作台」的视角：可以是 3/4 俯视的椭圆环），十五个席位，黄铜编号 1–15，十五号与一号相邻。下方（或环外）是 38 枚圆形的肖像徽章（只取头部，`App.portrait` 放进圆形遮罩）。
- **交互**：把徽章拖到席位上（`Draggable` + `InertiaPlugin`；拖动时身后拉出一根红线连到原位置，落座时 `drop` 音效 + 席位闪一下黄铜光）。点击徽章再点席位也能落座（手机端用这个）。席位上的人可以拖走、拖到别的席位互换。已经入座的人在徽章区变暗。
- 按钮（极简，两三个字）：「随机」——席位洗牌般快速闪过人像后定格（像老虎机），「清空」。
- 计数：如「11 / 15」用等宽小字。
- 每次变化：写入 `App.state.seats`（长度 15，元素为角色 id 或 null），`App.store.set('seats', ...)`，并 `App.bus.emit('cast:change', App.state.seats)`。页面加载时如果存储里有，就还原。
- 光标：席位靠近光标时微微抬起、编号发亮；拖动中光标所在的空席位有吸附预览。
- `palette`：近黑，光色骨白偏暖；`track: 'gallery'`。

## 文字

只出现名字、称号、编号、档位、台词、两三个字的按钮。不要任何说明。
