# 板块：受命（cycle）—— 一局游戏的循环

你的文件：`assets/js/sections/cycle.js`、`assets/css/cycle.css`。

## 配置依据（读 `主持人游戏.md` 第二、三、七节，`运行规则.md` 第 6 章）

一局游戏是一个循环：

1. **受命**：主持人秘密指定一名受命者，经私人通知送达。受命者须在二十四小时内造成符合任务条件的死亡，逾期将被公开受命者身份并处死。
2. **行凶**：任何人都可能杀人；期限内发生谋杀，期限即以实际死亡时刻结束。
3. **发现**：存活在馆、不是凶手的人看见尸体，构成有效发现。全馆广播：「发现尸体。调查时间一百二十分钟，于〈开庭时刻〉在穹顶议事厅开庭。」（敲钟人生效时为三十分钟。）
4. **调查**：一百二十分钟。届满，主持人移走尸体。
5. **庭审**：在一层穹顶议事厅，全员坐在各自席位上（自己来不了的由主持人放到席位上）。辩论：从一号席起每人发言一次，再公开讨论；主持人宣布「辩论结束，开始投票。」投票记名，从一号席起依次公开。
6. **判定与处刑**：选中真凶 →「判定正确。〈某某〉是〈死者〉一案的凶手。」处死凶手；选错 → 先处死被选中的人，再公布「判定错误。〈某某〉不是〈死者〉一案的凶手。本场第一次误判。」第二次误判后本批结束，真凶逃过审判继续参加游戏。
7. **余波与重新起算**：审判结束，每名存活者各得五枚金币（查明时再各得五枚；未查明时凶手的十枚出现在他套房的书桌上，不通知任何人）。存活在馆的现任受命者重新取得完整二十四小时。循环回到第 1 步。

`LORE.phases` 与 `LORE.broadcasts` 里有整理好的阶段与广播原句；以原文为准。

## 创意方向

这是一段**电影式的滚动叙事**（pin 一段很长的滚动，约 7–9 屏），每一步一个满屏的「镜头」，几乎没有字，只有馆内广播的原句和巨大的阶段名。像弹丸论破章节之间的硬切 + 人狼村之谜的水墨与阴影。

镜头建议（可以更好，但每一步都要有）：

1. **受命**：一片黑。屏幕中央浮现一张小小的私人通知（像一张折起的卡片），展开——巨大的「受命」二字。接着一个巨大的等宽倒计时 `24:00:00` 开始走；**光标移动得越快，倒计时走得越快**（时间被你的焦躁加速）。
2. **行凶**：倒计时骤停在某个时刻。画面变成走廊的透视（深色线条），一道人影掠过；墨/血从光标处晕开（Canvas 墨迹扩散，随光标留下痕迹，几秒后干涸成锈红）。
3. **发现**：硬切——全屏闪粉（`App.flash`）、`discover` 音效、`App.bg.pulse()`、屏幕震动（`App.shake`）；广播句用 `App.text.type` 打出来：「发现尸体。调查时间一百二十分钟，于 19:42 在穹顶议事厅开庭。」（开庭时刻按发现时刻 +120 分钟计算出来）
4. **调查**：一个巨大的圆环计时器（120 分钟）随滚动耗尽；画面上散落着看不见的痕迹（鞋印、血点、玻璃碎片、钟表——取自 `LORE` 的线索/尸体变化），**只有在光标的放大镜里才看得见**（放大镜 = 光标周围一个圆形区域，用 mask 显示隐藏层，放大 1.4 倍）。
5. **庭审**：十五席的环，从一号席起依次亮起（发言），一条条红线从投票者射向被投者，得票数在头顶跳动；「辩论结束，开始投票。」
6. **判定**：画面一分为二（斜切）：左边「判定正确。」右边「判定错误。」，随光标的水平位置，哪一边被推到前面（光标左/右决定哪个结局占据画面）。然后是处刑：剪影被一道斜切的血粉光吞没。
7. **余波**：金币像雨一样落在圆桌上（Canvas，五枚、十枚），一枚滚到画面边缘；然后一切倒卷回到「受命」——画一条回到起点的环（循环箭头不要用图标，用一道收拢的光或倒放的动效），循环感。

人名：取 `App.state.seats` 里的人（随机挑凶手/死者），没有就从 `App.chars` 随机；名字代入广播句。监听 `cast:change` 更新。

## 其他

- 每一个镜头的阶段名用巨大的竖排 `--f-display`（或 `--f-brush` 血字，择一统一），两个字：受命、行凶、发现、调查、庭审、判定、余波。
- `palette`：随镜头变化（受命/行凶 深红，发现 闪粉，调查 冷灰，庭审 暗金，判定 血红，余波 黄铜）——在你的 ScrollTrigger 里调用 `App.bg.setPalette`。`track: 'investigation'`（进入庭审镜头时可以 `App.audio.setMood({tension: 1})`）。
- 音效：`tick`、`heartbeat`、`discover`、`type`、`stamp`、`vote`、`execute`、`coins`、`whoosh`、`slash`。
- 手机端：保留顺序与核心演出，光标效果改为触摸位置或自动动画。
