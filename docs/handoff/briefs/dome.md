# 板块：醒来（prologue）与 终章（wish）

你的文件：`assets/js/sections/prologue.js`、`assets/css/prologue.css`、`assets/js/sections/wish.js`、`assets/css/wish.css`。
两个板块是首尾呼应的一对：开头在穹顶议事厅的圆桌旁醒来，结尾回到同一张圆桌，只剩一把椅子还亮着。

## 配置依据（读原文核对）

- `开局配置.md`：T0 第一日 17:00；全员坐在穹顶议事厅圆桌旁的乌木扶手椅上，一人一席；按席位分五批自然醒来：1、6、11 号 17:01；2、7、12 号 17:02；3、8、13 号 17:03；4、9、14 号 17:04；5、10、15 号 17:05。
- `洋馆物理层.md` §1.1/1.3/6.2：穹顶议事厅 17.2×14 m，最高净高 7.8 m，穹顶起拱 4.6 m；东侧收纳台上有钥匙龛（十五把编号钥匙按号悬挂）和白玉理币盘（150 枚金币，十五摞每摞十枚）；东墙南段嵌着价目铜牌；落地钟 17:00 五声报时（遮幕已经播放了五声钟响）。
- `主持人游戏.md`：十五席围圆桌成环，十五号与一号相邻；最终只剩一人时，主持人实现其任何愿望。

## prologue（醒来）—— 网站的第一屏，必须惊艳

- 遮幕的眼睑睁开后（bus 事件 `wake`），看到的是**从穹顶正上方俯视**的圆桌：乌木圆桌、十五把扶手椅环绕，椅背上有黄铜编号（Cinzel 罗马或阿拉伯数字均可，统一即可）。穹顶的肋拱从画面边缘向中心汇聚（透视线），整个画面像一只巨大的眼睛。
- **光源就是光标**：桌子和每把椅子都投下长长的影子，方向背离光标，随光标实时转动、拉长缩短（每帧计算）。光标离开画面时，光源回到穹顶中央。
- 醒来演出：`wake` 之后，按配置分五批，每批三把椅子上「睁开一双眼睛」——椅子上是人的剪影（用 `App.portrait(id, {silhouette:true})` 或你自己的剪影头部，眼睛发出该角色的 accent 光），伴随一声轻响（`App.audio.sfx('tick')` 或 `'drop'`）；屏幕一角的大号等宽时钟从 17:00 跳到 17:01……17:05。坐着的人：若 `App.state.seats` 里有人就用他们，否则从 `App.chars` 随机取 15 人。
- 标题「十五席」：巨大竖排 `--f-display`，带一点点血粉；副标题极小：「第一日 17:00」或拉丁小字 `FIFTEEN SEATS`。入场用 `App.text.reveal`。
- 滚动（pin 一段）：镜头从正俯视慢慢倾斜成斜俯视（CSS 3D `rotateX`），圆桌后退变小，椅子的编号一个个亮起，最后整个场景沉入黑暗、过渡到下一板块（洋馆）。可以在过渡中让一把黄铜钥匙从钥匙龛落下、带入下一板块的意象。
- 极少文字：标题、时刻、编号。不写任何介绍。
- `palette` 建议：底色偏暖黑，光色黄铜；`track: 'dread'`。

## wish（终章）

- 回到同一张圆桌（同样的俯视构图，视觉上要让人一眼认出「回来了」）。
- 滚动推进时，十五把椅子**一把接一把熄灭**（每熄一把，一声低沉的 `tick`/`heartbeat`，椅子的编号变成锈红色、剪影倒下或消失），直到只剩最后一把被穹顶顶端落下的一束光照着。
- 最后那个人：若模拟庭审产生了胜者（`App.state.winner` 为角色 id，或监听 bus 事件 `trial:winner`），就让他坐在那把椅子上，显示他的肖像（`App.portrait`，视线追随光标）和他的愿望台词（`character.lines.wish`）；否则这个位置的人在 38 人中缓慢轮换（剪影 → 片刻显形 → 又沉回黑暗），每次浮出一句他的 `lines.wish`。
- 一句话：「只剩一人时，愿望将被实现。」（或从 `主持人游戏.md` 第六节取更贴切的原句，≤ 16 字）。
- 光标在黑暗中移动时，会照出漂浮在空中的其他人的愿望低语（各角色 `lines.wish`，很淡，靠近才清晰，离开就散成墨）。
- 结尾：一个「再睡一次」的按钮——眼睑合上（自己做两片眼睑动画），回到页面顶部，再次睁眼（可以复用：触发 bus 事件 `wake`，prologue 会重演醒来）。
- 页面最底部极小的落款：「十五席」与一个黄铜圆环标记。
- `palette`：几乎全黑，光色骨白，`glow` 低；`track: 'wish'`。

## 光标与音效

- 两处都要让光标成为光源；椅子影子的实时计算是这一板块的招牌效果，务必顺滑。
- 用到的音效：`tick`、`drop`、`heartbeat`、`chime`、`whoosh`。
