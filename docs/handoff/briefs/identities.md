# 板块：身份（identities）

你的文件：`assets/js/sections/identities.js`、`assets/css/identities.css`。

## 配置依据（读 `主持人游戏.md` 第一、四、五节原文）

- 十五组身份：`WORLD.identities[]`，每组有正位 `front` 与逆位 `back`，卡面原文 `frontText`、卡背原文 `backText`。
- 丘比特与圣女没有逆位：`noReverse: true`，此时卡背与正面同文（`backText === frontText`）。圣女发动接任后「变为贞德」（`state: '贞德'`）。
- 身份卡实物（`开局配置.md` §4）：63×88 mm，比扑克厚而硬挺，正反两面各印一段黑字，字高约 3 mm；撕不开、剪不断、烧不着、泡水不坏、划不出痕，折过自己弹平。T0 时平放在每间套房书桌中央，正面朝上。
- 每张身份卡附有共同说明（`主持人游戏.md` 第五节开头的引用块），可以作为卡底的极小印字。
- 成为受命者时，视为同时拥有逆位身份（逆位卡面第一行就是「受命者视为同时拥有此身份。」）。

## 创意方向

身份牌是这个游戏的核心道具，要做得像塔罗牌一样有魅力、有重量。

1. **发牌**：进入板块时（pin），十五张牌从屏幕外一张张飞入（`card` 音效），在桌面上排成一道弧形扇面（或环形）。牌背朝上 → 依次翻成正面。
2. **扇面跟随光标**：光标横向移动时，扇面像被手指拨动一样转动；离光标最近的那张牌抬起、放大，带 3D 倾斜（跟随光标的 rotateX/rotateY），表面有一道随光标移动的全息/金箔反光（`conic-gradient` 或 `linear-gradient` + `mix-blend-mode`）。
3. **牌面设计（重点）**：
   - 正位（正面）：骨白色厚卡纸，黄铜双线边框，四角哥特式角花（SVG），顶部罗马数字编号（I–XV），中央是该身份的纹章（`App.sigil(front)`，黄铜色），下方是身份名（`--f-display`），再下方是卡面原文的小字（真实印在卡上的字，字号可以很小，悬停/聚焦时才清晰），最底一行极小的共同说明。
   - 逆位（背面）：黑漆底，锈红与血粉的细线边框，纹章 `App.sigil(back)` 用血粉，身份名倒置或镜像的处理（逆位 = reversed），第一行「受命者视为同时拥有此身份。」用血粉强调。
   - 两面版式统一成一套，像同一副牌。
4. **点击一张牌**：它飞到画面中央放大（其余牌暗下去后退），可以读清卡面文字；「翻面」（两个字的按钮，或直接点牌面）→ 3D 翻转到背面（`flip` 音效 + 一瞬间的色差 `App.glitch`），背面出现时背景烟雾转为血红（`App.bg.setPalette`）、`App.bg.pulse()`。左右切换上一张/下一张（按钮 + ←/→ 键），Esc 或点空白处放回扇面。
5. **圣女**：她的卡背与正面同文。给她的牌一个特别交互：长按（按住 1.2 秒，有一圈进度环）=「发动」——牌面上的「圣女」二字被火烧穿（遮罩 + 火星粒子），烧出「贞德」二字。这是条文里写的「发动后，圣女变为贞德」。松开前放手则取消。
6. **丘比特**：没有逆位，卡背与正面同文；翻面时给一个不同的反馈（翻过去还是同样的字——制造一种「它没有另一面」的诡异感）。
7. 极少文字：卡面原文、身份名、编号、按钮「翻面」。
8. 手机端：扇面改为横向可滑动的牌列，点击放大，按钮翻面。

## 其他

- `palette`：偏紫的墨黑，光色黄铜；逆位聚焦时切到血红。`track: 'gallery'`。
- 音效：`card`、`flip`、`hover`、`glitch`、`whoosh`。
- 纹章正由另一位画师绘制，名称就是身份中文名（`App.sigil('法官')` 等，含 `'贞德'`）。占位是一个带首字的圆形，不要因为占位而改设计。
