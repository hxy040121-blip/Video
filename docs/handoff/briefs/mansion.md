# 板块：洋馆（mansion）

你的文件：`assets/js/sections/mansion.js`、`assets/css/mansion.css`。

## 配置依据

- `WORLD.rooms`：由 `洋馆物理层.md` §1.3 生成的 106 个空间，每个有楼层、净内坐标（米；原点西南角，x 向东，y 向北；每层净内 52×36）、面积、门（方向、位置坐标、宽度、通向哪里、是否敞口）、所属（小室）。
- `LORE.rooms`：每个空间的氛围短句（mood）、陈设（objects）、是否有窗、地面材质。
- 楼层：B1（−4.8 m，层高 4.8）、1F（0，层高 8.4，套房 1–5）、2F（8.4，层高 6.0，套房 6–10）、3F（14.4，层高 5.2，套房 11–15）。三座楼梯（主楼梯厅、西北楼梯厅、东北楼梯厅）四层贯通。
- 一层迎宾前厅南墙正门（x=26，宽 2.4 m）外侧紧贴连续的**黑钻石封墙**：馆内没有通向室外的通道。
- `洋馆物理层.md` §3.1 光：05:00—07:00 窗光由无渐亮；07:00—17:00 窗光恒定最亮、有窗房间灯灭；17:00—19:00 由亮渐无；19:00—23:00 无窗光、灯亮；23:00—05:00 灯低亮（三米内认得出熟人）。§3.2 哪些房间有窗。
- 读 `洋馆物理层.md` 第 1、3、6 节，确保画出来的东西都对得上。

## 创意方向

洋馆是整个游戏的舞台。这里要让人「走进」这栋建筑，感受到它的尺度、封闭和不怀好意的精致。

1. **四层叠放的立体模型**：每层平面用 SVG 按真实坐标精确绘制（墙、门洞、套房编号、楼梯），四层像四块薄薄的黑色玻璃/乌木板，等轴测地上下叠放（CSS 3D：`perspective` + `rotateX(55–60deg) rotateZ(-40deg)` 之类），线条用黄铜色细线。光标移动让整个模型轻微转动（视差），离光标近的房间边缘发亮。
2. **滚动驱动（pin）**：先是四层合在一起的整体，随滚动层与层拉开；然后依次「抽出」每一层（建议顺序 1F → 2F → 3F → B1：醒来的地方在 1F 的穹顶议事厅），被抽出的楼层旋转放平成正俯视的大平面图，其他层退到一侧缩小。
3. **平面图的交互**：
   - 平面默认是暗的，**光标是一盏手提灯**：以光标为中心的圆形区域照亮平面（CSS mask 或 SVG radialGradient mask），其余部分只剩极淡的轮廓。
   - 悬停房间：房间填充微亮，房名（衬线，小）+ 氛围短句（极小）在光标旁浮现；门的位置用小缺口画出。十五间套房用黄铜编号标出；穹顶议事厅在 1F 上有一个缓慢的血粉脉冲（你醒来的地方）。
   - 点击房间：短暂放大该房间（Flip 或 GSAP），显示它的 2–4 件陈设（`LORE.rooms[].objects`），像证物标签一样散开，再点关闭。
4. **光的时段**：一个小小的表盘（或横向的刻度尺）可以拖动时间 00:00—24:00。拖动时，有窗的房间按 §3.1 的规则亮起/暗下（窗光），低亮时段整个平面更暗、手提灯的半径缩小到「三米」对应的比例。默认读 `App.state.minutes`（滚动驱动的馆内时间），拖动后以拖动值为准。
5. **黑钻石封墙**：1F 迎宾前厅南墙的正门处画出一道闪烁的黑钻石纹样（细小的菱形阵列，随光标闪光），悬停时出现两个字「封死」之类的极短词（或者不写字，只让光标靠近时菱形变成血粉色、轻微震动）。
6. 楼梯：三座楼梯在立体模型里用竖直的细线贯穿四层；放平后的平面图上标出楼梯厅。
7. 手机端：放弃 3D 叠放，改成楼层切换标签 + 可点的平面图，光照用点击位置代替光标。

## 文字

只出现：楼层名（B1 / 1F / 2F / 3F 或 地下一层…）、房名、编号、≤ 14 字的氛围句、时刻。

## 其他

- `palette`：底色偏冷的暗褐，光色黄铜；`track: 'dread'`。
- 音效：悬停房间 `hover`，抽出楼层 `whoosh`，点击房间 `click`，拖动时间 `tick`（每小时一声），封墙 `glitch`。
- 离开视口暂停所有循环。
