# 板块：铜牌（plaque）—— 价目铜牌与 150 枚金币

你的文件：`assets/js/sections/plaque.js`、`assets/css/plaque.css`。

## 配置依据（读 `价目表.md` 全文与 `洋馆物理层.md` §6.2、§9，`主持人游戏.md` 第八节）

- 「兑换方式」和第一到第六节刻在穹顶议事厅东墙南段的**价目铜牌**上，铜牌上刻的就是这几段原文（`WORLD.prices.how` 与 `WORLD.prices.chapters`）。
- 兑换：说出要换的东西，在心里说也可以；报价之后同意即成交；用身上带着的金币付，一枚一百分，按整枚付，不找零；东西出现在身边；未列之物问价即答。
- 开局：150 枚金币在同一收纳台的白玉理币盘内，十五摞、每摞十枚，整列居中。
- 第六节「离场」：**退出券一张 50,000 分**（= 500 枚金币）。整座馆开局只有 150 枚。
- 审判发放：一批审判结束，每名存活者各得五枚；查明真凶时再各得五枚；未查明时真凶独得十枚，放在他套房的书桌上，不广播。

## 创意方向

1. **铜牌**：一块真实感很强的黄铜牌，嵌在暗色石墙里。用 CSS 渐变 + SVG 噪点做出拉丝金属质感；文字是**雕刻**效果（内凹：上暗下亮的 text-shadow，或者 SVG filter）。**光标是一束掠射的光**：铜牌表面的高光和每个刻字的反光随光标位置实时移动（用 `--mx/--my` 或自己的 pointermove），这是这一板块的招牌效果。
   - 排版：标题「价目」；兑换方式四行；六节分栏（食物、日用与舒适、药与医疗、工具与器械、防护、离场），条目与分数用点线连接。分数用 Cinzel/等宽数字。
   - 「离场 · 退出券一张 50,000」单独占据铜牌最底部的一条，刻得更深，边缘有血粉的极细光。
2. **理币盘**：铜牌下方（或旁边）是一只白玉理币盘，十五摞、每摞十枚金币，整列居中（Canvas 2D 或 CSS 3D 均可，要有体积和金属光泽，随光标反光）。
   - 悬停一摞：那一摞微微发亮，金币轻轻叮当（`coin` 音效）。
   - 点击一摞：取走一枚，金币弹进右下角的「你的钱袋」（一个小计数 + 金币图标，飞行轨迹带拖影）。盘里的金币真实减少，总数 150 枚封顶。
3. **兑换**：钱袋里有金币时，悬停铜牌上的条目会显示需要几枚（小金币图标排成一行，超过 10 枚就用数字），点击条目 = 兑换：金币从钱袋飞向条目、熔进铜牌（`coins` 音效），条目刻字一瞬发亮，然后物品名用墨色从光标处浮现（「东西出现在身边」）。金币不够：条目抖一下（`wrong`），钱袋闪红。按整枚付，不找零（例如 30 分的东西也要付一枚）。
4. **退出券**：悬停时，画面上浮现一个对比：盘中 150 枚 vs 需要 500 枚（例如 500 个空的圆圈轮廓排开，其中只有 150 个被金币填满——或者其他更有冲击力的可视化），不写解释。点击：钱袋不够——铜牌深处传来一声闷响，整块铜牌轻震，退出券那一行的血粉光熄灭片刻。
5. 钱袋状态写入 `App.state.coins`（数字），并在 `App.bus.on('trial:coins', n => ...)` 时把模拟庭审里赢得的金币加进来（若庭审板块发出此事件）。
6. 极少文字：铜牌原文本身、数字。不加任何解释。
7. 手机端：铜牌单栏，光源跟随触摸/陀螺仪均可（触摸即可）。

## 其他

- `palette`：暖黑，光色明亮的黄铜，glow 稍高；`track: 'gallery'`。
- 音效：`coin`、`coins`、`wrong`、`hover`、`click`、`door`（闷响）。
