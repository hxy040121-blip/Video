# 立绘样张：新画风提案

## 背景

网站「十五席」是一个杀人推理角色扮演游戏的艺术展示站，风格诡异、悬疑，参照《弹丸论破》与《人狼村之谜》，配色是墨黑 + 暗金（黄铜）+ 克制的荧光血粉（`#ff2e7e`）。仓库 `/home/claude/Video`。

上一轮的 38 张立绘被主人否决了：**「效果过于差了，风格也不对」**。它们的问题（你一定要避开）：
- 像廉价的扁平矢量头像生成器：千篇一律的模板脸、同样的鼻子嘴巴、温吞的微笑、塑料感的平涂。
- 一点都不诡异、不悬疑；没有光影、没有气氛、没有张力。
- 绘画功力不够的地方（脸部结构、手）暴露无遗。

你可以看一眼旧稿避开它们：`node tools/render-svg.mjs --out <临时目录>/old.png --cols 3 --cell 300 assets/art/portraits/l.svg assets/art/portraits/junko.svg assets/art/portraits/itachi.svg`

现在要做的是**一种新画风的样张**，给主人挑选。你负责其中一个方向（见你的任务说明）。另有其他画师同时做别的方向。

## 样张内容

用你的方向画三位角色，**同一画风**：
- `l`（L，《死亡笔记》）
- `junko`（江之岛盾子，《弹丸论破》）
- `itachi`（宇智波鼬，《火影忍者》）

角色说明：`assets/data/characters.js` 里每人的 `art` 字段，以及 `人物卡/<名>.md` 的「外貌」一条（以人物卡为准）。

文件写到：`<临时目录>/samples/<方向字母>/<id>.svg`（不要写进 assets/，不要动 assets/ 里的任何文件）。辅助脚本放在 `<临时目录>/samples/<方向字母>/work/`。

## 技术要求（网站要能直接替换使用）

- `viewBox="0 0 600 800"`，胸像构图，头部大约在画面上半部中央（双眼约在 y=300—340），透明背景或你的方向需要的自带底色（若自带底色，铺满 0–600×0–800）。
- 网站会让眼珠追随光标、会眨眼：每只眼睛 `<g class="p-eye">`，里面一个外包裁切组 `<g clip-path="url(#<id>-eyeL)"><g class="p-iris">…会动的部分…</g></g>`；clip-path **不能**挂在 `.p-iris` 自己身上；`.p-eye` 与 `.p-iris` 上不能写 `transform` 属性。闭眼/被遮的角色也要有一个可动的 `.p-iris`（比如黑暗里的一点反光）。
- 整体放在 `<g class="p-body">`（身体）与 `<g class="p-head">`（头）里。画到 0–600×0–800 之外的形状要被 `<clipPath id="<id>-frame"><rect width="600" height="800"/></clipPath>` 裁掉。
- 所有 id 以 `<id>-` 开头。不要 `<text>`、`<image>`、`<script>`、外部引用。**尽量不要用 `filter`**（38 张同屏会卡）；需要纹理时用 `<pattern>`（排线、网点）或直接画出来。每个文件 ≤ 80 KB。
- 角色签名色（`art.accent`）可以用，也可以统一改用网站的血粉/黄铜——以画面好看、全体统一为准。

## 质量标准

- 这是主人会第一眼判断「网站简不简陋」的东西。宁可风格大胆、简化，也不要画得平庸。
- **识别度**：熟悉这些角色的人要一眼认出是谁（发型轮廓、标志性服饰与饰物、神态）。
- **气氛**：诡异、悬疑、有压迫感；眼神是重点。
- **统一**：三张放在一起要像同一位画师、同一款游戏。
- 每张至少五轮「渲染 → 用 Read 看 → 找出最弱的地方 → 改」。渲染：`node tools/render-svg.mjs --out <png> --cell 420 <svg>`（工具在 /home/claude/Video 下运行；`--bg` / `--cellbg` 可改底色；`--look 1,0` 检查眼珠平移）。
- 最后做一张展示图：`node tools/render-svg.mjs --out <临时目录>/samples/<方向字母>/sheet.png --cols 3 --cell 360 --bg '#0a0809' --cellbg '#0a0809' <三张svg>`（如果你的方向在别的底色上更好看，就用那个底色）。

不要运行 git，不要调用任何 `mcp__hearthbot__` 工具。最终消息：三行以内的画风说明（给主人看的，中文，不要术语堆砌），以及 sheet.png 的路径。

## 三个方向（每个方向一位画师，各画上面三张）

- **A 「黑影」**：每个角色都是一团深黑剪影，像弹丸论破学级裁判里身份未明的黑影、人狼村之谜夜里的狼。识别度靠夸张而精确的外轮廓（发型、领口、饰物），加一条沿一侧边缘的细轮廓光（黄铜色或角色签名色）给出体积。黑影内部只露出少数东西：发光的眼睛（眼白与虹膜都亮，带一圈淡光晕），以及适合该角色的一个笑容或一个标志细节（盾子的黑白熊发饰；鼬领口的红云纹和划痕护额；L 的黑眼圈大眼）。效果要让人发冷：觉得这些影子在看着你。透明背景；在 #0a0809 和昏暗的黄铜光背景上都要检查。
- **B 「墨影」**：恐怖漫画 / 木刻版画的明暗，只有三个色值：骨白纸色 #ebe3d6、墨黑 #0b0809、一个克制的强调色（血粉 #ff2e7e 或角色签名色），只用在眼睛、嘴唇或一处服饰细节。从一侧或从下方打来的硬光：大块纯黑阴影吞掉半张脸和大部分身体；中间调只用排线 / 网点表现。脸用大胆的图形化形状画（参考伊藤润二、Mike Mignola、日本木刻），不要柔和的动漫赛璐璐——形状更少、更果断。每张立绘都在自己的骨白纸卡上，铺满 600×800（边缘可以有轻微磨损），38 张放在一起是一套。
- **C 「铜版」**：维多利亚钢版雕刻肖像，像每位客人的肖像被刻好挂在洋馆的肖像走廊里。用细雕刻线、排线与交叉排线塑造形体（不用平涂），黄铜色 #c29a5b、高光 #e3c48a，画在近黑 #0a0809 上，外面是与身份纹章同款雕刻风格的椭圆浮雕框（双圈、小菱形；先看 `assets/art/sigils/*.svg`）。只有眼睛带颜色：角色签名色或血粉 #ff2e7e 的冰冷反光。气氛是闹鬼的肖像画：庄重、古老、在注视你。

样张做完后拼成一张对比图（三种方向 × 三位角色）给主人挑。主人选定前不要画全部 38 张。
