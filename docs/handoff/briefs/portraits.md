# 角色立绘（38 张，统一画风）

> 旧 brief：这里规定的赛璐璐画风已被主人否决（2026-10-02）。只参考其中的流程与结构要求；`.p-iris` 的裁切写法以 `assets/art/portraits/_STYLE.md` 第 0 节为准。新画风见 `portrait-samples.md` 与 `docs/HANDOFF.md`。

你是一位插画师兼 SVG 工匠。网站「十五席」（一个杀人推理角色扮演游戏的艺术展示站，风格参照《弹丸论破》与《人狼村之谜》）需要 38 位登场者的胸像立绘，**画风必须完全统一**，像同一位画师为同一款游戏画的立绘。

仓库：`/home/claude/Video`。先读 `docs/design-system.md` §4（立绘规范）。角色数据在 `assets/data/characters.js`（每人的 `art` 字段是给画师的说明：剪影特征、发型发色、眼睛、肤色、脸部特征、服装与配色、饰物、表情、签名色 accent），还可以读 `人物卡/<名>.md` 的「外貌」一条核对。

## 画风（所有人一致）

- **动漫赛璐璐 + 墨线**：平涂色块、硬边阴影，像游戏里的立绘（sprite）。不写实，不用复杂渐变；头发上最多一个简单的线性渐变或几道硬边高光。
- 构图：`viewBox="0 0 600 800"`，透明背景，胸像（锁骨/胸口以上，肩膀在画面底部被裁掉），头部中心约 x=300，双眼约在 y=300—340，头顶约在 y=110—170（夸张发型可以更高），统一取景——不因身高改变大小。头部略带 3/4 侧角度或正面均可，但全体要一致：**统一为正面略偏 3/4（脸朝向画面左侧约 15°）**，这样排成一排时像在同一个空间里。
- 线条：外轮廓 `#0b0809` 粗 5，内部线 2–2.5，圆端点、圆连接。
- 阴影：光从左上来；每个区域一块硬边阴影形状，用 `fill="#000" opacity="0.25"`（脸）到 `0.35`（衣服）叠在色块上。
- 眼睛是重点：较大的动漫眼，粗而锋利的上睫毛线，彩色虹膜（带一圈更深的外缘和一个瞳孔），一个白色高光。表情要「不安」：每个人带着自己的那种危险感（见 `art.expression`）。
- 签名色 `art.accent` 至少出现在一处（领带、发饰、眼睛、衬里……），该元素加 `class="p-accent"`。
- 不要画背景、地面、文字、边框。不要 `<text>`、`<image>`、`<script>`、外部引用、滤镜（filter）——保持纯矢量形状，网站会统一加后期。

## 网站要控制的结构（必须严格遵守）

```
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 600 800">
  <defs>
    <clipPath id="<id>-eyeL"><path d="...与左眼白相同的形状..."/></clipPath>
    <clipPath id="<id>-eyeR"><path d="..."/></clipPath>
  </defs>
  <g class="p-hair-back">…</g>      (可选：头发后层)
  <g class="p-body">…</g>           (脖子、肩膀、衣服)
  <g class="p-head">
    …脸、耳朵…
    <g class="p-eye">
      <path class="p-sclera" d="..."/>
      <g class="p-iris" clip-path="url(#<id>-eyeL)">  ← 虹膜 + 瞳孔 + 高光，网站会把它平移 ±7px 追随光标
        <circle .../> …
      </g>
      …上睫毛线、下眼线（在 p-iris 之后画，盖在上面）…
    </g>
    <g class="p-eye"> …右眼同理… </g>
    …眉毛、鼻、嘴…
    <g class="p-hair-front">…刘海、前发…</g>
  </g>
</svg>
```

- 所有 `id` 以 `<id>-` 开头（如 `l-eyeL`）。
- 虹膜要比眼白可见区域稍大一点或刚好，平移 ±7px 时不能露出眼白之外的东西（clipPath 保证），也不能让眼睛看起来「空了」。
- 闭眼/遮眼的角色也要有可动的 `p-iris`（比如绷带缝隙里的一点反光）。
- 每个文件 ≤ 60 KB。

## 工作方法

1. 先读 `assets/art/portraits/` 里已有的样板（若有）——**它们是画风基准，你的线宽、阴影、眼睛构造、脖子与肩膀的处理必须和样板一致**。
2. 每画完一个，渲染检查：`node tools/render-svg.mjs --out <临时目录>/<id>.png --cell 360 assets/art/portraits/<id>.svg`，用 Read 看。再把它和样板放在一起渲染一张对照图检查统一性：`node tools/render-svg.mjs --out <临时目录>/cmp-<id>.png --cols 4 --labels <样板...> assets/art/portraits/<id>.svg`。还要用 `--look 1,0` 和 `--look -1,-1` 渲染，检查眼珠平移时是否正确。
3. 每个角色至少迭代三轮：可辨认度（只看剪影能不能认出是谁？标志性的发型、帽子、领口、饰物是否到位）、画风统一、表情的不安感、细节（耳环、伤疤、纹样）。
4. 识别度第一：这些是知名角色（L、夜神月、江之岛盾子……），观众应该一眼认出。要准确画出他们的标志性特征（发型轮廓、配色、服装、饰物）。

不要运行 git，不要调用 `mcp__hearthbot__` 工具。最终报告：列出画了哪些、每个的识别要点、你不满意的地方。
