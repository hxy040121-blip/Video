# 死与税

1. 启用的那一刻，主持人播报：

   > 由于某位玩家的行为，触发了事件：死与税。所有玩家前往议事厅集合。

2. 人到齐、坐好以后（事件通则），主持人播报：

   > 该事件结束前所有人无法转让金币，也无法发起交易。十分钟后，从一号开始轮流投票，获票最高者，将失去所有的金币。没有唯一最高者的，将扣除每人500积分，不够的死亡。

3. 从这条播报起到事件结束，金币不能转手：谁给谁金币、谁拿谁的金币，都不成立，金币留在原主那里；兑换也不成立。
4. 十分钟到，从一号席起，在座的人依次投票：每人一票，可以投自己，不投的算投自己，不在座的不投；身份能力不作用于这次投票。得票唯一最多的人，身上带着的和自己藏起来的金币当场全部消失。没有唯一最多的，全员每人扣五百积分（主持人游戏第 8 节）。事件到此结束。
