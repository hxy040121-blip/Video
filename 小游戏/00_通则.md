# 小游戏通则

本文件管主持人的小游戏怎样进行；主持人点名一场小游戏时，和同名的那一份一起读，照它写（运行规则第 0 节）。

**赌局里的千。** 出千照现实的道理：没人看见、没人当场拿住的，就算成了。抓千要当场拿得出东西；只凭推测、凭看出来的不对劲去指认，对方一句"那又怎样"就过去了。抓住了、抓空了各怎样，照各文件。

**篇幅。** 每一步写出过程（运行规则 2.5）：一招一式、一手一手写清楚，不概括；一局分几条回复写，跟着局里的事走。

**流程。**

1. 主持人先播报"请所有玩家前往议事厅集合。"活着在馆的人都到了、各坐自己的席位以后，再照文件"公布"一节公布难度、类型、人数、场地，请各位在十分钟内决定参与的人。昏迷的、自己来不了又没人帮的、不肯来的，不等他。要等的人此刻都已经在议事厅里的，不播这一句，直接公布。
2. 人物自己商量，没有人再提异议，就算决出；手里有 B 的人可以直接指定，指定了就算决出。被定下的人不能推辞。十分钟没决出的，全员每人扣五百积分（主持人游戏第 8 节）；罚完，演出者停笔，等主持人指定参与者或者取消这一场（运行规则 2.2 甲项）。
3. 主持人播报"参与者确认：〈房号〉。"接着照文件往下写。
4. 分出胜负；场地在洋馆之外的，白光先把各人送回出发时的位置。演出者再照下面的格式写出播报，接着往下写。C、惩罚点名时没给的，停在用到它的那一句以前，等主持人给（运行规则 2.2 甲项）。胜：`游戏结束，〈房号〉胜利。请在十分钟内选择奖励，除积分外的奖励不得转让。十分钟内未选择的，视为放弃。A：金钱：〈数额〉积分。B：权力：下一次小游戏时指定参与者的权力。C：个人：〈主持人定〉。`败：`游戏结束，〈房号〉失败。`接着报出主持人定的惩罚。

**胜负同时成立。** 胜利和失败的条件同时成立的（两边同时倒下、一同淹死、同时动手），参与者失败；文件另写了的，照文件。

**打不下去。** 胜负的条件谁也达不到、又停不下来的（伤不到对方，伤了马上长好，或者两边都不肯再打），演出者停笔交给主持人（运行规则 2.2 甲项）。

**奖励。**

- A，金钱：简单 2,000，中等 4,000，较难 7,000，极难 10,000 积分，照主持人游戏第 8 节以金币给出。
- B，权力：主持人的下一场小游戏，由他直接指定参与者。到时他已死或已离馆的，作废。指定的人数要和那一场的参与人数一样，都是活着在馆的人，不重复；不合的，不算指定，B 不用掉，可以当场重指。几个人都有的，下一场里谁先指定就照谁的，同一刻指定的照席位号小的；这一场过后，这几个人的 B 都用掉了。
- C，个人：主持人定，点名时给出，或者分出胜负后给出。
- 几个人同时胜利的，各选一样；合作的游戏同胜同负。十分钟没选的，视为放弃。积分以外的奖励不得转让。

**惩罚。** 主持人当场定。


**白光。** 白光只用在洋馆之外的场地，只用来搬人。开始时，把所有人从各自所在的地方送到场地；文件写明的，把参与者送离场上，此后他是虚影；结束时，把各人送回出发时的位置。白光一闪，人已经在那一头，谁也看不清经过，躲不开，挡不住。

**能力回归。** 只在文件写明"能力回归：有"或主持人另说时才有：参与者卡上"失效"一条里的能力全部回来，能力自身的弱点和限制也一起回来；卡上写明是别人加给他的限制和祸害，不跟着回来，他原本知道有这样东西的，也觉得出它不在了；原作里他打架用的兵器和道具，卡上"随身物"写明不在他身上的，也回到他身上。持续到游戏结束。

**原作的本事和身体。** 能力回来的参与者，和小游戏里的对手，本事和身体都照原作。一下打出去，照原作结果就是定的：对方挡不住、躲不开，或者这一下根本伤不到对方，这是物理上确定的事，不掷（运行规则 5.1）；两边照原作都说得通的，才照 5.3 掷。挨了打伤成什么样、多久好、怎样才死，照他原作里挨过的、分量最接近的那一回。运行规则 5.6 的表和身体结算第 6、7 节照普通人的身体定，只用在原作里身体本来就是普通人的人身上。文件另写了怎样算的，照文件。

**死不带回。** 在洋馆之外的场地里因这场游戏死去的人，游戏结束时照样随白光回到出发时的位置，身体回到出发时的样子，活着。这样的死不进案件，也不结束行凶期限。不是因这场游戏死的，是真死，照主持人游戏第 3 节。人物不知道这一条，问到也不答；他们照会丢命来对待（运行规则 1.1、4.6）。

**结束。** 主持人为小游戏给出的道具收回，主持人说留下的才留下；在场地里得到的东西不带回来。小游戏里受的伤都治好，衣物不修；回来的能力和兵器、道具收回。

**馆内场地。** 场地是洋馆里某一处的，主持人确认参与者以后接着说"请参与者在〈n〉分钟内到〈场地〉。"时限照文件，文件没写的，十分钟。参与者自己走去，没有参加的人照常行动。到时还没进场的参与者失败，游戏照文件里有人中途退出的办法往下走。

**馆外场地。** 小游戏在洋馆之外的场地进行时，主持人和文件没有另说的，照下面办：

- 场地里的时间与馆内同步。
- 没有参加的人，以虚影在场观看。
- 游戏结束，各人回到出发时的位置，身体回到出发时的样子：场地里受的伤和体力消耗不带回来。饿、渴、困按经过的时间照常计算。
- 场地算在馆里：谁在不在馆、馆内有没有人死、身份能力管到全馆的，连这处场地一起算，人在场地里不算离馆，要报人在哪里的，报这处场地；馆里的时段表、天气和事件改的光，不带到场地上。开庭的时刻到了，或者启用了要所有参与者集合的事件，场地里的这一场还没结束的，等它结束、人回到馆里再开庭、再集合。不是因这场游戏死的，尸体在游戏结束时照死时的样子随白光回到他出发时的位置，不复原；期限、发现和调查照主持人游戏第 2、3 节，从实际死亡、有效发现的那一刻算，场地的时间和馆内不同步的，照回到馆里的那一刻算。

**虚影。** 虚影可以在场地里自由走动，彼此交谈。五感照常，场上的风、热、震动都感觉得到，但伤不到他们，推不动他们，也不会让他们失去意识。场上的人和物从虚影身上穿过，虚影也碰不到、改变不了场上的任何东西。虚影彼此也碰不到：身子和手里拿着的东西，都从对方身上穿过去。参与者看得见、听得见虚影；场地里的其他人看不见，也听不见。

**场内的规则。** 规则复杂、听一遍记不全的游戏，除了口头宣布，场地里另有一样东西把规则摆在眼前，在场的人随时看得到；是什么、在哪里，由文件写明。
